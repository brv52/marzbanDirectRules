domain — точное совпадение хоста (без поддоменов).

domain_suffix — сам домен и все его поддомены (например, 1transcribe.com покроет и app.1transcribe.com, а "ru" — всю зону .ru).

domain_keyword — любое вхождение подстроки в домен (используйте осторожно, чтобы не зацепить лишнее).

ip_cidr — конкретные IP (/32) или подсети (сюда удобно добавить вашу нестандартную офисную сеть 191.168.31.0/24, которую встроенный Bypass LAN пропускает как публичную).

Ненужные блоки можно удалить; следите, чтобы не было лишних запятых после последнего элемента массива.
